Product principles

Serious backend.

01 / SCHEMA

TypeScript is the source of truth.

Collections generate validation, database tables, REST routes, OpenAPI, and a typed client.

defineCollection('posts', { ... })
02 / RUNTIME

One process. One binary.

Bun, SQLite, auth, storage, realtime, backups, and the admin UI travel together.

base serve --init
03 / OWNERSHIP

Your server. Your data.

Deploy to a VPS, Docker, or your laptop. Move, inspect, export, and restore at any time.

base db backup

Quickstart

From zero to API
in three commands.

No account. No project wizard. Choose your binary and start building locally.

macOS ARM ↓ Linux x64 ↓ Linux ARM ↓ Windows ↓
base — zsh ● ● ●
$ curl -fL https://github.com/abdullah-bl/base/releases/latest/download/base-linux-x64 -o base 
# install, then create your backend
$ chmod +x base && sudo mv base /usr/local/bin/base
$ mkdir my-backend && cd my-backend
$ base init
✓ Created collections.ts and .env

$ base serve
✓ API ready at http://localhost:3000
✓ Admin ready at http://localhost:3000/_/
